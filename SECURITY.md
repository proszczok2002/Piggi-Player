# Bezpieczeństwo

## Obsługiwane wersje

Poprawki bezpieczeństwa są przygotowywane dla najnowszego wydania dostępnego w GitHub Releases.

## Zgłaszanie podatności

Nie publikuj w zwykłym Issue szczegółów pozwalających wykorzystać podatność. Użyj prywatnego zgłoszenia bezpieczeństwa GitHub, jeśli jest dostępne dla repozytorium, albo skontaktuj się z właścicielem przez profil [proszczok2002](https://github.com/proszczok2002).

W zgłoszeniu podaj wersję aplikacji, wersję Androida, opis wpływu oraz możliwie mały przykład odtworzenia problemu. Nie dołączaj prywatnych plików audio ani danych użytkownika.

## Integralność wydań

Oficjalne APK są publikowane wyłącznie w GitHub Releases i podpisane stałym certyfikatem wydawniczym. Updater dodatkowo porównuje SHA-256 pliku z manifestem wydania.

# Piggi Player 1.1.0

Wydanie przenosi oficjalny kanał aktualizacji do GitHub Releases i dodaje sekcję wsparcia projektu.

## Zmiany

- updater pobiera manifest i APK bezpośrednio z GitHub Releases,
- obsługiwane są bezpieczne przekierowania GitHub,
- odpowiedzi HTTP i SHA-256 APK są obowiązkowo weryfikowane,
- w Ustawieniach dodano sekcję „Wsparcie” z PayPal i Revolut,
- dodano testy updatera, publiczną dokumentację i automatyczny Android CI.

Wymagany Android 10 lub nowszy.

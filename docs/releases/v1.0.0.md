# Piggi Player 1.0

Pierwsze publiczne wydanie Piggi Player na GitHub.

## Najważniejsze elementy

- lokalna biblioteka muzyki bez konta, reklam i telemetrii,
- playlisty, ulubione, kolejka, timer snu i korektor,
- odtwarzanie w tle przez Android Media3,
- Chromecast dla lokalnych plików,
- obsługa Androida 10 lub nowszego,
- podpis zgodny z dotychczasowymi instalacjami Piggi Player.

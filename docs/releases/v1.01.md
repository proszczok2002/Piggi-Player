# Piggi Player 1.01

Testowe wydanie przygotowane w celu sprawdzenia pełnej ścieżki aktualizacji przez GitHub Releases.

## Zmiany

- zwiększono `versionCode` do 18, aby aplikacja wykryła nowe wydanie,
- zachowano wszystkie funkcje i poprawki z wersji 1.1.0,
- bez zmian funkcjonalnych w odtwarzaczu.

Po opublikowaniu updater powinien zgłosić wersję `1.01`, pobrać podpisany APK z GitHuba i sprawdzić jego SHA-256 przed uruchomieniem systemowego instalatora.
